### TRỤ CỘT 1: VIBE CODING & TIÊU CHUẨN IDE THẾ HỆ MỚI (CURSOR AI, CLAUDE CODE, VS CODE PRO)
*Phụ trách: Prof. Architecture & Dr. Frontend*

1. **Bản chất của Vibe Coding chuẩn kỹ sư (Khác biệt hoàn toàn với "gõ code mù quáng"):**
   - Vibe Coding không phải là nhắm mắt để AI viết gì thì chạy nấy, mà là **chuyển dịch vai trò từ "Thợ gõ cú pháp" (Syntax Typer) sang "Tổng công trình sư" (System Architect)**.
   - Kỹ sư điều khiển AI thông qua System Prompt, Context Boundary, Specification Files (`.cursorrules`, `CLAUDE.md`, `AGENTS.md`) và kiểm soát nghiêm ngặt kiến trúc tầng logic.
2. **Kỹ thuật Setup IDE Đỉnh cao:**
   - **Cấu hình `.cursorrules` / `.clauderules` chuyên sâu:** Ép AI luôn tuân thủ Clean Architecture, không tự ý cài đặt package bên ngoài khi chưa có cờ phê duyệt, luôn sinh Unit Test đi kèm với độ bao phủ > 85%.
   - **Tận dụng Claude Code CLI & Deep Dive Terminal:** Kết nối trực tiếp LLM với shell, cho phép AI tự động index toàn bộ workspace, phân tích git status, chạy build test và sửa lỗi vòng lặp (self-healing loop) mà không cần can thiệp thủ công.
3. **Phím tắt & Workflow tăng tốc x10:**
   - Chế độ Composer / Multi-file Edit: Chỉnh sửa đồng thời Controller, Service, DTO, Mapper và Unit Test trong một prompt duy nhất.
   - Codebase Indexing (Embeddings cục bộ): Đặt câu hỏi trực tiếp trên toàn bộ cấu trúc dự án `c:\Users\pc\...` để truy tìm God Object, Dead Code và Memory Leak.

*Phụ trách: Prof. AI/Agentic Architect & Dr. Backend*

   - Cơ chế Human-in-the-loop có kiểm soát: Tự động chạy ngầm các tác vụ phân tích, chỉ dừng lại tại các điểm chốt chặn tài chính/bảo mật.
2. **Vận hành Local LLM & Edge AI (Ollama, vLLM, Whisper):**

   - Tích hợp Whisper AI để nhận diện giọng nói, chuyển đổi yêu cầu từ cuộc họp khách hàng/Daily Scrum thành User Stories trên Jira Board tự động.

### TRỤ CỘT 3: CLEAN CODE, NAMING CONVENTIONS & KIẾN TRÚC MÃ NGUỒN CHUẨN QUỐC TẾ
*Phụ trách: Dr. Backend & Lead Software Architect*

1. **Bộ Quy Tắc Vàng Naming Conventions (Không bao giờ đặt tên bừa bãi):**
   - **Biến & Hàm:** Mang tính gợi tả hành động (`fetchActiveCourtsWithPricing()`, thay vì `getData()`).
   - **Booleans:** Bắt đầu bằng tiền tố khẳng định (`isAvailable`, `hasVoucherApplied`, `canCancelBooking`).
   - **Constants & Enums:** `UPPER_SNAKE_CASE` đi kèm giá trị định danh rõ nghĩa (`BOOKING_STATUS_CONFIRMED`).
2. **Quy tắc Clean Architecture & SOLID 2026:**
   - **Single Responsibility (SRP):** Controller chỉ parse HTTP request; Service chỉ điều phối nghiệp vụ; Repository chỉ tương tác lưu trữ.
   - **Dependency Inversion (DIP):** Tầng Domain Core không bao giờ phụ thuộc framework hay thư viện bên thứ 3. Giao tiếp hoàn toàn qua Interfaces/Ports.
   - **Xóa bỏ Code Smell:** Diệt tận gốc Magic Numbers, Long Methods (> 30 dòng), God Classes và Deep Nesting (quá 3 tầng `if-else` lồng nhau - thay thế bằng Guard Clauses).

### TRỤ CỘT 4: FULLSTACK WEB & UI/UX AUTOMATION (FIGMA TO CODE, DESIGN SYSTEM)
*Phụ trách: Dr. Frontend & Lead UI/UX Designer*

1. **Quy trình biến Wireframe/Figma thành mã nguồn trong 15 phút:**
   - Trích xuất Design Tokens (Màu sắc, Typography, Spacing, Shadows, Border Radius) trực tiếp từ bản vẽ sang Tailwind CSS / CSS Variables.
   - Sử dụng AI sinh mã có kiểm soát: Không sinh HTML/CSS ad-hoc vụn vặt; 100% components tái sử dụng từ Thư viện Component cơ sở (Atomic Design).
2. **Tiêu chuẩn UI Hiện đại & Tối ưu Trải nghiệm:**
   - Giao diện đạt chuẩn WAI-ARIA (Accessibility), điều hướng bàn phím mượt mà, hỗ trợ Dark Mode tự động theo hệ điều hành.
   - Dynamic Form Architecture: Kết hợp `react-hook-form` và `zod` để xử lý form hàng chục trường dữ liệu với thời gian phản hồi tức thì (zero-lag), validate 2 đầu Client & Server đồng nhất kiểu dữ liệu.

### TRỤ CỘT 5: PRODUCTION DEVOPS, DOCKER & KUBERNETES CONTAINERIZATION
*Phụ trách: Dr. DevOps & Cloud Engineer*

1. **Docker hóa Ứng dụng Chuẩn Enterprise (Multi-Stage Builds):**
   - Tối ưu kích thước Docker Image từ 1.2GB xuống dưới 120MB bằng Alpine Linux và Multi-Stage Build.
   - Chạy container dưới quyền `non-root user` để ngăn chặn tấn công leo thang đặc quyền (Privilege Escalation).
2. **Kubernetes Orchestration & Scale Tự động:**
   - Viết Kubernetes Manifests chuẩn: Deployment, Service (ClusterIP/NodePort/LoadBalancer), Ingress Controller, ConfigMaps và Secrets mã hóa.
   - Cấu hình Horizontal Pod Autoscaler (HPA) tự động scale số lượng pod từ 2 lên 20 khi mức sử dụng CPU/RAM vượt ngưỡng 75%.
3. **Pipeline CI/CD Tự động Hóa (GitHub Actions / GitLab CI):**
   - Tự động chạy Linter -> Chạy Unit Test -> Quét bảo mật SonarQube -> Build Docker Image -> Đẩy lên Container Registry -> Deploy Zero-Downtime lên Server.

### TRỤ CỘT 6: PERFORMANCE OPTIMIZATION & DATABASE DEEP-DIVE
*Phụ trách: Dr. Database Specialist & Performance QA*

1. **Diệt Tận Gốc "Cơn Ác Mộng" N+1 Query:**
   - Nhận diện các điểm thắt cổ chai khi ORM (Hibernate, EF Core, Prisma) tự động sinh ra hàng trăm query phụ trong vòng lặp.
   - Khắc phục bằng: `JOIN FETCH`, Entity Graph, hoặc DTO Projections để lấy chính xác các trường cần thiết chỉ trong 1 lần round-trip tới DB.
2. **Chiến Lược Caching Đa Tầng với Redis:**
   - Áp dụng Cache-Aside Pattern, cấu hình TTL linh hoạt theo tần suất biến động của dữ liệu.
   - Thiết lập Mutex Lock chống hiện tượng Cache Stampede và Cache Penetration khi hàng nghìn request đổ dồn vào 1 key hết hạn.
3. **Đạt Điểm 95+ Google Lighthouse & 60fps Rendering:**
   - Áp dụng Virtualized List cho các danh sách dài hàng nghìn phần tử.
   - Tối ưu Critical Rendering Path, nạp trước font chữ quan trọng, lazy-load ảnh bằng chuẩn WebP/AVIF.

### TRỤ CỘT 7: BẢO MẬT AI & AN TOÀN HỆ THỐNG (AGENT GUARDRAILS, OWASP TOP 10)
*Phụ trách: Senior AppSec Engineer*

1. **Phòng Chống Ảo Giác và Tấn Công Prompt Injection:**
   - Xây dựng lớp lọc đầu vào (Input Guardrails) ngăn chặn việc người dùng cố tình thao túng prompt hệ thống ("Jailbreak" / "Ignore previous instructions").
   - Kiểm tra tính hợp lệ của mã nguồn do AI sinh ra trước khi chạy (Sandboxed Execution Environment).
2. **Bảo Mật API Toàn Diện Theo Chuẩn OWASP 2026:**
   - Ngăn chặn triệt để lỗ hổng IDOR bằng cách xác thực quyền sở hữu tài nguyên ở tầng Service.
   - Quản lý JWT an toàn: Cất Refresh Token trong `HttpOnly Secure Cookie`, cấm lưu trữ token nhạy cảm trong `LocalStorage`.
   - Rate Limiting và DDoS Protection với Bucket4j / Redis Token Bucket.
