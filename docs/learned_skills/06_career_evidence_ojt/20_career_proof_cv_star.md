## 🚀 Kỹ Năng Đã "Nạp" Vào Não Bộ Triều Hí:

### 1. Công Thức Google XYZ - Biến Dự Án Thành "Bằng Chứng Sống"
Tuyệt đối loại bỏ các câu văn sáo rỗng: *"Tham gia phát triển dự án", "Học hỏi ngôn ngữ Java"*. Thay thế bằng công thức định lượng:
> **Accomplished [X] as measured by [Y], by doing [Z]**  
> *(Đạt được thành tựu X, được đo lường bằng chỉ số Y, thông qua hành động kỹ thuật Z)*

- **Ví dụ Junior sao chép:** *"Xây dựng tính năng đặt sân và thanh toán cho hệ thống quản lý sân."*
- **Ví dụ Kỹ sư thực chiến do Triều Hí huấn luyện:**  
  *"Xây dựng phân hệ đặt sân thời gian thực xử lý 1.200 request/phút với độ trễ dưới 150ms, bằng cách triển khai Distributed Locking trên Redis (Redisson) chống Race Condition và tối ưu hóa truy vấn SQL diệt triệt để lỗi N+1 Query."*

### 2. Tiêu Chuẩn "Project Evidence" Đánh Gục Hệ Thống Lọc ATS
Một CV đẳng cấp năm 2026 bắt buộc phải gắn kèm 4 đường link bằng chứng làm việc thật:
1. **GitHub Repository:** Lịch sử Git Flow chân thực, có Pull Request, commit đều đặn, code clean.
2. **Swagger / Postman Public Documentation:** Danh sách API spec có mô tả chi tiết, schema chuẩn.
3. **Architecture Diagram (Mermaid / System Design):** Chứng minh ứng viên hiểu bức tranh tổng thể, không chỉ gõ code cục bộ.
4. **Live Demo URL hoặc Video Loom 3 phút:** Giới thiệu ngắn gọn kiến trúc kỹ thuật và demo tính năng trực quan.

### 3. Làm Chủ Buổi Phỏng Vấn & Bảo Vệ Đồ Án Bằng Phương Pháp STAR
Khi CTO hoặc Technical Lead đặt câu hỏi tình huống hóc búa:
- **S (Situation - Bối cảnh):** Mô tả ngắn gọn hoàn cảnh dự án, độ phức tạp của bài toán.
- **T (Task - Thách thức):** Chỉ rõ mục tiêu khó khăn cần vượt qua (ví dụ: deadline gấp, hệ thống bị nghẽn mạng).
- **A (Action - Hành động cá nhân):** Trình bày chính xác những quyết định kỹ thuật do CHÍNH BẢN THÂN thực hiện (không nói "nhóm em làm", mà nói "tôi đã phân tích log, phát hiện deadlock và tái cấu trúc transaction").
- **R (Result - Kết quả & Bài học):** Đưa ra con số cụ thể chứng minh sự thành công và đúc rút kinh nghiệm sâu sắc.
